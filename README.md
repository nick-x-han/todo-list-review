# Todo List Review

This is a review of the todo list project of the Odin Project.

## Setup

Run `npm install` to install dependencies and generate `package-lock.json`.

## Development

Run `npm run dev` or `npm start`.

## Build

Run `npm run build`.

## Deployment

Run `bash deploy.sh`.

For a repository created from this template, make sure the `gh-pages`
branch exists before the first deployment.
